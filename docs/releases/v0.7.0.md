# easy-uds v0.7.0 — Again Easily

Fast by default. Easy by design. Powerful when needed.

0.6 focused on building and validating the engine. 0.7 focuses on making that
engine easier and safer to use.

## Start with the beginner API

```cpp
#include <easy_uds/simple.hpp>

using namespace easy_uds::simple;

Server server("/tmp/demo.sock");

server.on("/ping") = "pong";

server.on("/echo") = [](std::string_view body) {
    return std::string(body);
};

server.run();
```

```cpp
Client client("/tmp/demo.sock");

auto pong = client.request("/ping");
auto echo = client.request("/echo", "hello");
```

Need explicit request metadata, streaming, FD passing, queue policies,
statistics or resource control? The Core API remains fully available.

## Included in 0.7.0

- Linux and C++17
- Unix Domain Sockets and protocol v2
- Fixed RPC, persistent `Session`, and streaming
- FD passing and peer credentials
- Backpressure and request-memory budgets
- Named serialization domains and `FIFO`, `LatestWins`, and `RejectIfBusy`
- `ServerStats` / `SessionStats`
- The `easy_uds::simple` beginner facade

## Not included

Windows, Python bindings, automatic reconnect, automatic retry/replay, typed
RPC, built-in serialization, protocol v3, multiple-FD frames, full-duplex
streaming, and a built-in logger or metrics exporter are outside this release.

## Compatibility and verification

Protocol v2 remains unchanged. There is no implicit retry or replay, and the
[0.6 → 0.7 migration guide](../migration/0.6-to-0.7.md) documents source-level
changes. The 0.6.4 performance gates remain in place. Alternating A/B runs on
native x86_64 and ARM64 found no reproducible native regression in the Simple
facade; the earlier WSL2 c32 variance is scheduler-sensitive. See the
[0.7 performance record](../PERF_0.7.md) and [release verification record](../RELEASE_0.7.md)
for measurements and the complete gate definition.

## After 0.7.0

The 0.7.x line is limited to bug fixes, documentation, and small compatibility
corrections. The Simple v1 surface stays intentionally small: no automatic
integer conversion, JSON, `simple::Session`, `simple::Stream`, or typed
arguments are planned for this line. The next themes are 0.8 Everywhere,
1.1+ Natural typed/declarative API research, after the 1.0 stable public
contracts are established.
