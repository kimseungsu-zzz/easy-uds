# easy-uds v0.7.1 — Architecture Release

easy-uds 0.7.1 closes the User/System and Linux backend architecture work
started in 0.7. It is not a feature or protocol release.

## Included

- Explicit `src/user/cpp` → `src/system` → `src/system/platform/linux`
  ownership documentation.
- Linux endpoint, readiness, peer identity, descriptor passing, socket I/O,
  synchronous wait, and server pathname capabilities kept behind concrete
  platform seams.
- CMake build-time source selection through common and platform source sets.
- Architecture checks that keep Linux implementation files out of common
  sources and prevent platform dependency re-entry.
- A P0/P1/P2 handoff list for the Windows-oriented 0.8 design.

## Compatibility

- Public Core and Simple APIs are unchanged.
- Protocol v2 and existing wire semantics are unchanged.
- No Windows backend, C ABI, Python binding, generic `NativeHandle`, or
  protocol v3 is included.

## Verification

The release gate covers static/shared GCC and Clang builds, CTest/RC tests,
compile-error diagnostics, package consumers, Simple API consumers, ASan/UBSan,
TSan, fuzz/stress coverage, and the existing performance/allocation gates.
Native x86_64 and ARM64 measurements remain workflow-controlled validation
jobs; a skipped hosted job is not represented as a passing measurement.

This document describes release scope only. Creating the annotated tag and
GitHub release remains an explicit maintainer action.
