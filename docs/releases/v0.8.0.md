# easy-uds v0.8.0 — Everywhere

Fast by default. Easy by design. Powerful when needed.

0.6 focused on building and validating the engine. 0.7 focused on making it
easier and safer to use. 0.8 carries that engine to Windows while keeping
Linux-only capabilities explicit instead of pretending that they are portable.

## Supported scope

- Linux and Windows 10+ AF_UNIX backends selected concretely at build time.
- Protocol v2, fixed RPC, persistent Session, streaming, backpressure, queue
  policies, statistics, and the Simple API.
- Linux peer credentials and one-FD `SCM_RIGHTS` passing.
- Windows Core/Session/streaming/Simple/lifecycle behavior and installed static
  and shared package consumers.
- Platform-neutral move-only `Request` with POSIX capabilities delivered
  through the explicit POSIX extension.

## Intentionally unsupported

Windows resource/HANDLE passing, Linux-style peer credentials or SID/token
identity on Windows, generic `NativeHandle`, automatic retry/replay, typed RPC,
protocol v3, C/Python bindings, and IOCP optimization remain outside 0.8.

## Validation

The final full validation passed in [GitHub Actions run
31919103353](https://github.com/kimseungsu-zzz/easy-uds/actions/runs/31919103353):

- Linux GCC/Clang static/shared builds and release gate;
- Windows static/shared Core, Session, streaming, Simple, lifecycle, public
  headers, and installed package consumers;
- ASan/UBSan, TSan, fuzz, stress, architecture guard, and Simple API checks;
- native x86_64 20-pass soak and ARM64 5-pass smoke/benchmark validation.

The repository environment has no local MSVC, so Windows validation is hosted
runner validation. The Windows performance smoke baseline is recorded in
[`docs/PERF_0.8_RC.md`](../PERF_0.8_RC.md); those runner-specific numbers are
not intended as a Linux parity claim.

The historical RC document remains available at
[`v0.8.0-rc.1.md`](v0.8.0-rc.1.md) for the candidate-era record.
