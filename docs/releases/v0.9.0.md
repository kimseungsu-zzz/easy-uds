# easy-uds v0.9.0 — Stabilization

easy-uds 0.9.0 closes the stabilization line and prepares the public API for
the 1.0 freeze. It does not add a new transport, protocol, or major API
feature.

## What changed

- Hosted Windows smoke stability was corrected by widening the test harness
  timeout for scheduler-sensitive runners.
- Request/POSIX capability documentation now matches the move-only,
  platform-neutral `Request` and callback-scoped descriptor/peer views.
- Public API, ownership/lifetime, error/deadline, Session, lifecycle, queue,
  streaming, architecture, and package surfaces were audited.
- A 0.9 stabilization roadmap records the 1.0 freeze inventory and deferred
  portability decisions.

## Compatibility

- Protocol version remains **2**; wire framing and request-id semantics are
  unchanged.
- Core and Simple API behavior remains unchanged.
- Windows resource/HANDLE passing, SID/token identity, generic
  `NativeHandle`, typed RPC, protocol v3, C/Python bindings, IOCP
  optimization, and automatic retry/replay remain intentionally unsupported.

runner.
