# easy-uds v1.1.0

Version 1.1.0 expands the local IPC library with opt-in protocol cancellation,
versioned C and Python interfaces, explicit idempotent retries, request
authorization, and platform-specific peer/resource capabilities.

## What's included

- Protocol v2 remains the default. Opt-in protocol v3 adds cooperative
  cancellation for persistent Session requests.
- The versioned C ABI provides fixed RPC, callback-scoped request context,
  persistent Sessions, cancellation, and caller-opt-in idempotent retries.
- The optional Python package wraps the C ABI using the standard library.
  Streaming remains available through the C++ API.
- C++ servers can authorize fixed requests before route dispatch using the
  request and callback-scoped peer context.
- Windows 10+ supports peer process IDs, best-effort process SID lookup, and
  one callback-scoped HANDLE on a fixed request. HANDLE transfer requires the
  server to obtain `PROCESS_DUP_HANDLE` access to the peer process.
- POSIX platforms retain peer credentials and one-descriptor `SCM_RIGHTS`
  requests. FreeBSD, OpenBSD, NetBSD, and DragonFly BSD backend sources are
  included; native builds and runtime validation remain pending.

## Compatibility and limits

The established C++ Core and Simple APIs remain available. Protocol v2 stays
the default and retains the 20-byte header. Protocol v3 requires both peers to
opt in. Cancellation is cooperative: handlers must inspect
`RequestContext::stop_requested()`, and operating-system calls are not forcibly
interrupted. Retries are limited to the explicit idempotent API; a caller must
ensure that repeating the operation is safe.

The C ABI is versioned independently from the C++ ABI. The project does not
promise binary compatibility between arbitrary C++ compilers or standard
libraries. C and Python handlers do not configure the C++ server-level request
authorization callback.

Linux remains the production backend. The WSL2/GCC static and shared release
gates passed with warnings as errors, all 11 CTest cases in each configuration,
installed package consumers, compile-error checks, and Simple API smokes.
Visual Studio 2022/MSVC built the Windows Debug configuration and its smoke
test passed, including peer-PID authorization and HANDLE transfer. A shared
library C ABI and Python smoke covered RPC, request context, Sessions, and
cancellation. GitHub Actions was disabled for this repository during release
validation, so the hosted workflow could not be run. BSD native validation is
not claimed for this release.
